ENTENDIMENTO DA ALTERAÇÃO

   Este Merge Request estabelece a base para a reescrita do invoice-core em Java/Spring Boot. Ele inclui uma estrutura de aplicação em camadas hexagonais, configurações de banco de dados, integração com GCP Pub/Sub, tratamento de erros via RFC 7807, e outras convenções de API. A implementação é executável e conectada ao banco de dados, mas ainda não inclui funcionalidades de negócios específicas.

   Alcance da mudança: serviço
   Motivo: A alteração afeta a estrutura e configuração de um serviço específico, sem impactar outros serviços ou módulos.

   Comportamento alterado:
   - A aplicação passa a usar Spring Boot 4.1 e Java 25.
   - Adicionado suporte a PostgreSQL 18 com Flyway para migração de esquema.
   - Implementado gerenciamento de identificadores UUIDv7.
   - Configurado health checks via Actuator com probes de liveness e readiness.

   Novos caminhos de execução:
   - Novo caminho para lidar com exceções globais através de GlobalExceptionHandler.
   - Novo caminho para publicação de mensagens através de MessagePublisher.
   - Novo caminho para consumo de mensagens através de AbstractPubSubConsumer.

   Contratos alterados:
   - Contrato alterado: adição de endpoints REST com URI versioning.
   - Contrato alterado: uso de RFC 7807 para tratamento de erros.
   - Contrato alterado: configuração de mensageria via PubSubProperties.

   Dependências afetadas:
   - Dependência externa afetada: Spring Boot 4.1.
   - Dependência externa afetada: Spring Cloud GCP.
   - Dependência externa afetada: PostgreSQL 18.
   - Dependência externa afetada: Testcontainers.
