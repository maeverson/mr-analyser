ENTENDIMENTO DA ALTERAÇÃO

   Este Merge Request estabelece a base para uma nova implementação de invoice-core-v2 usando Spring Boot 4.1 e Java 25. A estrutura inclui configurações para saúde, persistência, identificadores UUIDv7, API conventions, integração com GCP Pub/Sub, logging estruturado e operações. O MR adiciona novos componentes como controladores de API, publicadores e consumidores de mensagens, e configurações específicas para diferentes ambientes (desenvolvimento, local, produção). A arquitetura segue um estilo hexagonal, com camadas separadas para domínio, aplicação, infraestrutura e API.

   Alcance da mudança: serviço
   Motivo: O MR afeta principalmente o serviço invoice-core-v2, introduzindo novas funcionalidades e configurações específicas para esse serviço.

   Comportamento alterado:
   - O comportamento anterior de invoice-core é substituído por uma nova implementação baseada em Spring Boot 4.1 e Java 25.
   - A integração com GCP Pub/Sub é adicionada, permitindo a publicação e consumo de mensagens.

   Novos caminhos de execução:
   - Novo caminho para lidar com exceções globais através da classe GlobalExceptionHandler.
   - Novo caminho para gerar identificadores UUIDv7 usando a classe UuidV7.
   - Novo caminho para configurar e usar o GCP Pub/Sub através das classes MessagePublisher e AbstractPubSubConsumer.

   Contratos alterados:
   - Contrato alterado: adição de novos endpoints de API com URI versioning.
   - Contrato alterado: adição de novas interfaces e classes para publicação e consumo de mensagens.

   Dependências afetadas:
   - Dependência externa afetada: Spring Boot 4.1
   - Dependência externa afetada: Java 25
   - Dependência externa afetada: PostgreSQL 18
   - Dependência externa afetada: GCP Pub/Sub
